# Муршрут

Пиксельная игра от [RGBY](https://rgby.ru): загрузи логотип или картинку с чётким силуэтом — и котёнок выйдет на ней погулять. Пара минут отдыха.

**Играть:** https://vynepravy.github.io/mur-walk/

Загрузи логотип или любую картинку с чётким силуэтом. Ночью котёнок выйдет на прогулку по её краям и оставит за собой неоновый след. Разгоняйся, притормаживай на поворотах, не свались. Пара минут, чтобы выдохнуть и побыть котом.

## Как играть

- Держи палец на экране (или кнопку мыши, или пробел) — котёнок бежит быстрее. Отпусти — тормозит.
- Оранжевый пунктир впереди — крутой поворот: сбавь скорость, иначе котёнок свалится. Каждый срыв — плюс 3 секунды.
- Между частями картинки котёнок прыгает сам.
- В конце — постер с твоим временем, его можно сохранить.

Картинка никуда не отправляется: всё происходит прямо в браузере. Лучшее время хранится только на твоём устройстве.

## Устройство

Один HTML-файл без библиотек и сборщиков. Шрифты — в папке `fonts`:
[Press Start 2P](https://fonts.google.com/specimen/Press+Start+2P) (CodeMan38) и [Pixelify Sans](https://fonts.google.com/specimen/Pixelify+Sans) (Stefie Justprince), оба по лицензии SIL Open Font License 1.1.
